# NNNN: Short name

- **Status:** proposed | accepted | rejected | postponed
- **Decision:** (by the maintainers, with the reasons, once made)

## Problem

What is hard or impossible today, with a program that shows it.

## Change

The new syntax, meaning or API, with examples.

## What it breaks

Programs that compile today and would not, or would mean something else.
If it breaks anything, it needs an edition (docs/reference/stability.md).

## Alternatives

What else was considered, and why not.

## Implementation

How `compiler/*.fd` implements it, what the Rust bootstrap needs (if
anything), the tests, and the flag it sits behind until it ships.
