## fmt_same_tokens

Check if source is already formatted. Returns true if formatting would
NOT change it.
Whether `a` and `b` hold the same tokens and comments in the same order
(only spacing and blank lines may differ): what formatting may change.
`fid fmt` writes nothing when this fails, so a formatter bug cannot
corrupt the file.
