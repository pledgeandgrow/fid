## ssa_takes

Does ssa_round_trip work on `f` at all? Not on @constant_time functions,
functions with TryUnwrap or Asm (ssa_has_unhandled), or functions whose
entry block has predecessors. ME3: iropt's `promote` (iro_promote), which
ssa subsumes, still runs on exactly these when ssa is on (iropt.fd
iro_promote_here), so no function loses the load forwarding it had.
