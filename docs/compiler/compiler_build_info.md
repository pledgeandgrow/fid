## fid_build_source

D9 (release-roadmap): a hash of the source fid was built from (every
.fd file of compiler/ but this one, and of stdlib/), "" in a
development build. `scripts/build-info.sh` writes it. When it is set,
inc.fd inc_compiler_hash (what every build cache is keyed on) is this
hash with the executable's size, instead of a hash of the whole
executable's bytes (a 50 MB read on every command).
