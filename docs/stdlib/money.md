## Money_new

Create new money from a cents amount. This is the "mint" function.
Calling this inside a @conserve function is a compile error.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
val a = Money_new(250);
val b = Money_from_dollars(1, 50);
val sum = Money_add(a, b);
assert_eq(Money_to_cents(sum), 400);
val d = Money_sub(Money_new(1000), Money_new(300));
assert_eq(Money_to_cents(d), 700);
```
