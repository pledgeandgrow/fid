## event_on

Subscribe `f` to `name` on the default bus. Every event_emit(name, x)
calls f(x); handlers run in subscription order. Returns the handler's
index (for event_remove_at).


*Example -- run as a test by `scripts/doctest.py`:*

```fides
fn h(x: i64) -> i64 { return x; }
event_on("e", h);
assert_eq(event_count("e"), 1);
```
