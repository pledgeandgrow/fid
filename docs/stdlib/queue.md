## Queue

A FIFO queue of i64 values backed by an inbox and an outbox stack.


*Example -- run as a test by `scripts/doctest.py`:*

q.enqueue(1);
q.enqueue(2);
q.enqueue(3);

assert_eq(q.peek_or(0), 2);
assert_eq(q.len(), 2);
assert(q.contains(3));
q.clear();
