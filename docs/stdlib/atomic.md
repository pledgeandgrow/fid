## atomic_new

A new atomic word holding `initial`.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
val c: Atomic = atomic_new(5);
assert_eq(c.fetch_add(2, Order::Relaxed), 5);
assert_eq(c.fetch_sub(1, Order::Relaxed), 7);
assert_eq(c.swap(10, Order::AcqRel), 6);
assert(c.compare_swap(10, 11, Order::SeqCst));
assert(!c.compare_swap(10, 12, Order::SeqCst));
c.store(3, Order::Release);
assert_eq(c.load(Order::Acquire), 3);
```

## memory_fence

A fence: with Acquire, Release or AcqRel it orders the plain and relaxed
accesses around it as such a load or store would. Every atomic operation
is SeqCst today, so a fence adds no ordering of its own.
