## sc_key_char

ASCII for a make-code honouring shift AND caps (caps flips letters).


*Example -- run as a test by `scripts/doctest.py`:*

```fides
assert(sc_is_make(0x1E));
assert(!sc_is_make(0x9E));
assert_eq(sc_base(0x9E), 0x1E);
assert_eq(sc_ascii(0x1E, false), 97);
assert_eq(sc_ascii(0x1E, true), 65);
val st = sc_mod_update(SC_LSHIFT(), 0);
assert_eq(sc_key_char(0x1E, st), 65);
assert_eq(sc_key_char(0x1E, sc_mod_update(SC_LSHIFT() | 0x80, st)), 97);
```
