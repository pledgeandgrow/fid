## channel_create

Create a bounded channel with the given capacity.
Returns a channel handle (i64) that can be shared across threads.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var ch = channel_create(4);
assert(channel_send(ch, 10));
assert(channel_send(ch, 20));
assert_eq(channel_recv(ch), 10);
channel_close(ch);
assert(channel_is_closed(ch));
assert_eq(channel_recv(ch), 20);
assert_eq(channel_recv(ch), CHAN_CLOSED());
```
