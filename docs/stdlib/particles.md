## particle_emitter_create

Create a particle emitter with the given max particles.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var em = particle_emitter_create(4);
assert_eq(particle_emitter_count(&em), 0);
particle_emitter_set_pos(&mut em, 10.0, 20.0);
particle_emitter_burst(&mut em, 2);
assert_eq(particle_emitter_count(&em), 2);
assert(em.particles.get(0).x == 10.0);
particle_emitter_burst(&mut em, 10);
assert_eq(particle_emitter_count(&em), 4);
particle_emitter_clear(&mut em);
assert_eq(particle_emitter_count(&em), 0);
```
