## dp_noise

Add Gaussian noise to a tensor for differential privacy.
sigma = sqrt(2 * epsilon * sensitivity^2 / num_samples)


*Example -- run as a test by `scripts/doctest.py`:*

```fides
use tensor;
var s: Vec<i64> = Vec::new();
s.push(2); s.push(3);
val t = ones(s);
val noisy = dp_noise(t, 0.5);
assert_eq(size(noisy), 6);
assert_eq(size(gaussian_noise(s, 1.0)), 6);
assert_eq(size(dropout(t, 0.5)), 6);
```
