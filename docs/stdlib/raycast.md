## ray2d_vs_aabb

Ray vs AABB (axis-aligned bounding box) in 2D.
AABB is defined by min corner (minx, miny) and max corner (maxx, maxy).


*Example -- run as a test by `scripts/doctest.py`:*

```fides
val r = ray2d_create(vec2(0.0, 0.0), vec2(2.0, 0.0));
val h = ray2d_vs_aabb(r, 5.0, -1.0, 6.0, 1.0);
assert(h.hit);
assert(h.t == 5.0);
assert(h.point.x == 5.0);
assert(!ray2d_vs_aabb(r, 5.0, 2.0, 6.0, 3.0).hit);
assert(ray2d_vs_circle(r, 10.0, 0.0, 1.0).t == 9.0);
```
