## Stack

A LIFO stack of i64 values backed by Vec.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var s = Stack::new();
s.push(1);
s.push(2);
s.push(3);
assert_eq(s.pop_or(0), 3);
assert_eq(s.peek_or(0), 2);
assert_eq(s.peek_at_or(1, 0), 1);
assert_eq(s.len(), 2);
assert(s.contains(1));
var rest: Vec<i64> = s.drain();
assert_eq(rest.get(0), 2);
assert(s.is_empty());
```
