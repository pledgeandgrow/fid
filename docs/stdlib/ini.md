## ini_parse

Parse INI text into a Vec<IniEntry> preserving document order.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var doc = ini_parse("name = app\n[server]\nport = 8080\ndebug = true\n");
assert_eq(ini_get(doc, "", "name"), "app");
assert_eq(ini_get_int(doc, "server", "port", 0), 8080);
assert(ini_get_bool(doc, "server", "debug", false));
assert_eq(ini_get_int(doc, "server", "missing", 7), 7);
assert(ini_has(doc, "server", "port"));
ini_set(&mut doc, "server", "port", "9090");
assert_eq(ini_get(doc, "server", "port"), "9090");
assert_eq(ini_keys(doc, "server").len(), 2);
```
