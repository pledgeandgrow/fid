## tp_init

Start `n` ranks, one process each (docs/reference/tensor-parallel.md):
this process's rank, 0 in the process that was started.
`FID_TP_WORLD=n` in the environment overrides `n`; `n <= 1` keeps one
rank, at most 32. A second call gives the rank again. `fid run` keeps
one rank.
