## brotli_decompress

Decompress a Brotli stream (Vec of bytes 0..255). Returns the decoded
bytes, or an empty Vec when the stream is malformed, truncated, has
data after its end, or would decode to more than 256 MB. A valid
stream of zero bytes also gives an empty Vec: use brotli_ok or
brotli_error to tell the two apart.

## brotli_ok

True when `data` is a complete, valid Brotli stream. This decodes the
stream; an empty brotli_decompress result with brotli_ok true is an
empty stream, with brotli_ok false an error.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var empty: Vec<i64> = Vec::new();
empty.push(59);
assert(brotli_ok(empty));
assert_eq(brotli_error(empty), "");
assert_eq(brotli_decompress(empty).len(), 0);
var cut: Vec<i64> = Vec::new();
cut.push(27); cut.push(22); cut.push(0);
assert(!brotli_ok(cut));
assert(str_len(brotli_error(cut)) > 0);
assert_eq(brotli_decompress_str(cut), "");
```

## brotli_compress_level

Compress `bytes` (values 0..255; higher bits are dropped) into a Brotli
stream (RFC 7932). `quality` 0 only stores (uncompressed meta-blocks);
1 to 11 search for matches, harder at higher qualities (6 is
brotli_compress's). Any Brotli decoder reads the result; the ratio is
below the reference encoder's (no dictionary, no context modelling).


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var b: Vec<i64> = Vec::new();
var i: i64 = 0;
while i < 300 { b.push(120 + i % 4); i = i + 1; }
val z: Vec<i64> = brotli_compress_level(b, 6);
assert(z.len() < 40);
assert(brotli_ok(z));
assert_eq(brotli_decompress(z).len(), 300);
assert_eq(brotli_decompress(brotli_compress_level(b, 0)).len(), 300);
```
