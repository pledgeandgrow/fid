## elf_str_at

Read a NUL-terminated string at offset o within the byte range
[start, start+size) — used on the shstrtab and strtab sections.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var b: Vec<i64> = Vec::new();
b.push(0); b.push(46); b.push(116); b.push(120); b.push(116); b.push(0);
assert_eq(elf_str_at(b, 1), ".txt");
assert_eq(elf_str_at(b, 0), "");
var h: Vec<i64> = Vec::new();
h.push(0x3E); h.push(0x00); h.push(0x01); h.push(0x00);
assert_eq(elf_u16(h, 0), 62);
assert_eq(elf_u32(h, 0), 0x1003E);
```
