## gameloop_create

Create a game loop targeting the given FPS.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var gl = gameloop_create(50);
assert(gameloop_dt(&gl) == 0.02);
assert_eq(gameloop_total_frames(&gl), 0);
val n = gameloop_step(&mut gl);
assert(n >= 0);
assert_eq(gameloop_total_frames(&gl), 1);
gameloop_stop(&mut gl);
assert(!gl.running);
```
