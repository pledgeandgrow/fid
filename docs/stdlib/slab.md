## slab_new

Slab of `capacity` objects of `obj_size` bytes (>= 4, so the free
link fits). Free list threads index+1 through each slot (0 = end).


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var s = slab_new(16, 2);
assert_eq(slab_alloc(&mut s), 0);
assert_eq(slab_alloc(&mut s), 1);
assert_eq(slab_alloc(&mut s), -1);
slab_free(&mut s, 0);
assert_eq(s.used, 1);
assert_eq(slab_alloc(&mut s), 0);
assert_eq(slab_off(&s, 1), 16);
```
