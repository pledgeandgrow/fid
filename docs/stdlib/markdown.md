## md_to_html

Convert Markdown text to an HTML fragment.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
assert_eq(md_escape("a<b & c"), "a&lt;b &amp; c");
val h = md_to_html("# Title\n\nSome **bold** text.");
assert(str_contains(h, "<h1>Title</h1>"));
assert(str_contains(h, "<strong>bold</strong>"));
assert(str_contains(md_inline("`x`"), "<code>x</code>"));
assert(!str_contains(md_to_html("<script>"), "<script>"));
```
