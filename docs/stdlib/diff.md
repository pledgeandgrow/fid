## diff_unified

Unified-diff rendering with `context` lines around each hunk and
"--- old_label" / "+++ new_label" headers.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
val ops = diff_lines("a\nb\nc", "a\nB\nc");
assert_eq(diff_change_count(ops), 2);
assert(!diff_is_empty(ops));
assert_eq(diff_format(ops), " a\n-b\n+B\n c\n");
assert(diff_is_empty(diff_lines("x", "x")));
assert_eq(diff_unified("x", "x", "old", "new", 3), "");
assert(str_starts_with(diff_unified("x", "y", "old", "new", 3), "--- old\n+++ new\n"));
```
