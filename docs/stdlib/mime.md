## mime_from_ext

MIME type for a file extension (with or without leading dot).
Returns "application/octet-stream" when unknown.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
assert_eq(mime_from_ext(".HTML"), "text/html");
assert_eq(mime_from_ext("nope"), mime_default());
assert_eq(mime_from_path("a/b/logo.png"), "image/png");
assert(mime_known("json"));
assert_eq(mime_base("Text/HTML; charset=utf-8"), "text/html");
assert_eq(mime_param("text/plain; charset=utf-8", "charset"), "utf-8");
assert(mime_is_image("image/png"));
assert(mime_is_text("text/css"));
```
