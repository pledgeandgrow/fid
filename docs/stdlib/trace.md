## trace_enabled

Whether FIDES_TRACE is set (to anything but "" or "0"), unless
trace_set_enabled switched tracing on or off. Read on each call, not
cached in a global: the traced calls run on any thread, and a global
written from a spawned task is a race the compiler rejects.

## trace_span_line

The JSON line of one span (without the newline).


*Example -- run as a test by `scripts/doctest.py`:*

```fides
assert_eq(trace_span_line("db", "q\"1", 12, true), "{\"span\":\"db\",\"detail\":\"q\\\"1\",\"us\":12,\"ok\":true}");
assert_eq(trace_span_line_ids("a", "", 1, false, 3, 0), "{\"span\":\"a\",\"detail\":\"\",\"us\":1,\"ok\":false,\"id\":3,\"parent\":0}");
trace_set_enabled(false);
assert(!trace_enabled());
```
