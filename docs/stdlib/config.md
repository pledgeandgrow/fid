## config_new

An empty set of declared keys.


*Example -- run as a test by `scripts/doctest.py`:*

```fides
var c = config_new();
config_opt(&mut c, "port", CONFIG_INT, "8080");
config_opt(&mut c, "debug", CONFIG_BOOL, "yes");
config_opt(&mut c, "ratio", CONFIG_FLOAT, "0.5");
config_load(&mut c, "", "FIDDOC_NO_SUCH_PREFIX_");
assert_eq(config_int(c, "port"), 8080);
assert(config_bool(c, "debug"));
assert(config_float(c, "ratio") == 0.5);
assert(!config_given(c, "port"));
assert_eq(config_str(c, "port"), "8080");
```

## config_load

Load every declared key: --name flag, then PREFIXNAME env, then the
file's key, then the declared default. A required key no source supplies
panics naming it; a value of the wrong kind panics naming it too.
