## bpe_new

Build a tokenizer. vocab_json: {"<tok>": id, ...}. merges_text: the
merges file content, one "left right" pair per line (header lines
starting with '#' are skipped).


*Example (native only) -- run as a test by `scripts/doctest.py`:*

```fides
var bp = bpe_new("{\"<unk>\":0,\"a\":1,\"b\":2,\"ab\":3}", "a b\n");
var ids = bpe_encode(bp, "ab");
println(int_to_str(ids.get(0)));   // 3
```
