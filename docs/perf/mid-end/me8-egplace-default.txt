# me8-egplace-default: placement in the e-graph pass (compiler/egraph.fd
# eg_place, Click's global code motion; docs/roadmap/llvm-roadmap.md ME8)
# made the default on the native paths (Nov 17).
#
# What changed in compiler/egraph.fd (Nov 17):
#  - egraph_run: placement runs unless FID_NAT_OFF=egplace,
#    FID_IROPT_OFF=egplace or `--no-pass egplace` names it off (eg_place_on;
#    it was opt-in, FID_IROPT_ON=egplace, which still names it on and is
#    now the default build). FID_NAT_OFF=egraph turns the e-graph and so
#    placement off.
#  - eg_place leaves functions with asm! (the outputs of an Asm are
#    operands peir_inst_operands does not list, so a value read only there
#    could have been moved after it) or TryUnwrap (a terminator defining a
#    value: "before the terminator" would be before an operand) as they are.
#  - eg_one: the placement count is added to the skeleton's (egskel) count
#    instead of replacing it.
#  - counts: FID_EGRAPH_STATS=1 prints
#      [egplace] functions F, placed N, hoisted H, sunk S, skipped K
#    (hoisted: moved to a block in fewer loops; sunk: moved down the
#    dominator tree; skipped: functions left alone for asm!/TryUnwrap), or
#    "[egplace] off"; FID_IROPT_STATS=1 prints "[egplace] placed N" (the
#    memo's entries included). The build's "[prof] native mid-end" line
#    (compiler/main.fd) already ends with "N placed by the e-graph".
#
# Evidence before the change (stage0, the one-stage fid of Nov 16, whose
# eg_place is the same algorithm, opt-in): `emit --nat` (Windows x64 on
# the machine layer) with FID_IROPT_ON=egplace FID_VERIFY=1 vs without:
#   test_midend_egplace.fd: both print the expected 14 lines, the
#     executables differ; "783 placed by the e-graph" (core and runtime
#     included) vs 0.
#   the per-program results of the small suite run with stage0 are below
#   (program, on/off result, values placed, exit of the "on" build).
#
# With this run's final compiler the numbers that decide whether placement
# stays on are taken by tests/tooling/egplace-default-check.sh (SAVE=1
# writes docs/perf/mid-end/me8-egplace.txt): default vs FID_NAT_OFF=egplace
# vs FID_NAT_OFF=egraph, FID_VERIFY=1, per program: placed, hoisted, sunk,
# build and run ms. If any program DIFFs or fails to build only with
# placement on and the cause cannot be fixed in eg_place, turn the default
# back off: in egraph_run, `var on_p: bool = on_e && eg_opt_in("egplace");`
# (and note it here).
#
# scripts/me-measure.sh does not measure this pass: it builds through
# `emit` without --nat (pe_ir on Windows, which runs no e-graph) and reads
# iropt's instruction counts, which placement does not change (it moves
# instructions, it adds or removes none).
