# op3-shared-analyses: the mid-end's analyses kept between passes
# (competitive-roadmap OP3), caches on (default) vs FID_IROPT_OFF=cfgcache.
#
# What is cached:
#   - the CFG with its dominator tree and intervals, per function shape
#     (compiler/checks.fd iro_cfg; key iro_cfg_key: block ids and
#     terminator targets; a new CFG gets a new `gen`)
#   - the loop tree found on it (checks.fd iro_loops: reused while the CFG
#     handed in has the `gen` it was found for)
#   - the use lists between the passes of one function (compiler/iropt.fd
#     iro_uses_entry, armed by iropt_native per function; forgotten by
#     iro_uses_forget after every pass that reports a change, and checked
#     against a key of next_value and every block's instruction ids)
# FID_IROPT_OFF=cfgcache turns all three off; FID_IROPT_STATS=1 prints
#   iropt: cfg built N, reused M
#   iropt: loops built N, reused M
#   iropt: uses built N, reused M
#
